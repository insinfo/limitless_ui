Validação declarativa

Date picker agora aceita liRules, liMessages e liValidationMode para compor com required, regras customizadas e submissão via liForm.

currentValueChange x userValueChange

currentValueChange acompanha alterações do model e do calendário. userValueChange dispara apenas quando o usuário escolhe ou limpa uma data pela interface.

Template de trigger

liDatePickerTrigger permite trocar o input visual por um badge, chip ou botão compacto sem perder foco, estado disabled, hooks de automação e posicionamento do calendário.

Hooks para Puppeteer

Use os hooks do trigger, navegação e dia para simular a seleção real no calendário sem buscar por texto do mês ou classes traduzidas.
